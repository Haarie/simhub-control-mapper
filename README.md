# SimHub Control Mapper layout for all games

One set of Control Mapper output roles for Assetto Corsa, ACC, AC Rally, AC EVO, RaceRoom, Dirt Rally 2.0, rFactor 2 and Rennsport. Roles are grouped by use. Games bind by button number, so keep these numbers fixed once bound.

## Files

- `config/ControlMapperPlugin.GeneralSettingsV2.json`: Control Mapper settings (SimHub `PluginsData\Common`). Close SimHub before replacing your own file, and back it up first. It also contains the input mappings and USB device IDs for my hardware.
- `docs/SimHub_Control_Mapper_all_games.xlsx`: rebind map (old to new button), per-game comparison, gaps, and the AC EVO bindings. Apart from the first sheet, the sheets use the old button numbers.
